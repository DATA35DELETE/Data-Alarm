# Data Alarm

Türkçe olarak geliştirilmiş, hafif ve performanslı bir Qt tabanlı alarm uygulamasıdır.

### Özellikleri

- Hafif ve performanslı
- Alarm sesi seçme imkanı
- Tüm işletim sistemlerine uyumluğu
- Qt tabanlı olması
- Açık kaynaklı
- Alarm geçmişi
- Alarm geçmişini CSV formatına geçirme
- Alarm geçmişini aktarma aktarma
- Alarm geçmişini içe aktarma
- Karanlık ve aydınlık mod
- Alarm zamanı gelince dikkat çeken efektler
- İlerleme çubuğu
